# HelixSign Console & Dashboard UI

A production-grade, enterprise **Next.js 15 + Tailwind CSS** application for function-invariant DNA steganography, adversarial provenance watermarking, and biological IP verification.

---

## 🚀 Quick Start

From within this `frontend/` directory:

```bash
# 1. Install dependencies
npm install

# 2. Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

- **Enterprise Navigation**: Dual-level contextual sidebars, unified header breadcrumbs, and command palette (`Ctrl + K`).
